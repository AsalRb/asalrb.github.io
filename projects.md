### Benchmarking Protein-Ligand Binding Site Prediction with Pseq2Sites
Bachelor thesis project benchmarking Pseq2Sites, a CNN + attention model for sequence-based protein-ligand binding-site prediction. The project involves preprocessing scPDB and PDBbind datasets, implementation of ProtTrans protein embeddings, and model evaluation to assess performance, identify limitations, and explore potential methodological improvements. [GitHub Link](https://github.com/AsalRb/Benchmarking_Protein-Ligand_Binding_Site_Prediction_with_Pseq2Sites)


### Exploring Relationships Between Ion Channels and lncRNAs in Gastric Cancer
Ongoing research project using TCGA-STAD RNA-seq data to investigate relationships between lncRNAs and ion-channel genes in gastric cancer. Applied differential expression analysis (DESeq2), WGCNA, and clinical-trait analysis to identify relevant co-expression modules and prioritize candidate lncRNAs and ion-channel genes for further investigation. [GitHub Link](https://github.com/AsalRb/Exploring_Relationships_Between_Ion_Channels_and_lncRNAs_in_Gastric_Cancer)


### Genetic Database
Designed and implemented a normalized relational database (up to BCNF) for genetic data management. Developed the database from entity-relationship modeling and schema design to SQL implementation in PostgreSQL (via pgAdmin4). The system supports storing and querying data on genes, RNAs, proteins, organisms, and users, with role-based access control and example datasets. [GitHub Link](https://github.com/AsalRb/Genetic_Database)


### Read Mapping and Genome Assembly
Implemented a complete NGS workflow on *E. coli* short-read data, including quality control (FastQC), de novo genome assembly (SPAdes, QUAST), and reference mapping (BWA, SAMtools). Evaluated assembly and mapping results using metrics such as mapping rates and read depth, and visualized read alignments in IGV for further assessment. [GitHub Link](https://github.com/AsalRb/Read_Mapping_and_Genome_Assembly)

### Identification of Xylanase Genes
Developed a bioinformatics pipeline to identify thermostable xylanase genes from rumen metagenomic datasets. The workflow included sequence similarity searches using BLAST+, clustering at 97% identity with CD-HIT to generate non-redundant representative sequences, multiple sequence alignment with Clustal Omega to identify conserved motifs, and HMM-based filtering to refine candidate sequences. The pipeline produced a curated set of high-confidence xylanase gene candidates. [GitHub Link](https://github.com/AsalRb/Identification_of_Xylanase_Genes_from_Rumen_Metagenome)


### Hierarchical Data Structure for Genetic Diseases
Developed a Python-based tree data structure to organize genetic diseases and their associated genes. Implemented search and insertion functions, hash tables for storing gene attributes (location, exons, type, and name), and a menu-driven interface for navigating and managing the hierarchical biomedical data. [GitHub Link](https://github.com/AsalRb/Hierarchical_Data_Structure_for_Genetic_Diseases_Using_Tree_Algorithms)
